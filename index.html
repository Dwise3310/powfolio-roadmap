Open work

Namecheap, then Vercel.

  1. Account at namecheap.com with an email you still control. Save the login outside the browser.
  2. Search powfolio.xyz first. If it is a premium listing, compare pow3folio.xyz. Do not buy hosting.
  3. Enable WhoisGuard. It is free and hides the personal address from public whois.
  4. Pay, turn on auto-renew, and write down the renewal date.
  5. Domain List, Manage, Advanced DNS. Delete the parking URL redirect.
  6. A record: host @, value 76.76.21.21. CNAME: host www, value cname.vercel-dns.com.
  7. Vercel project pow3folio, Settings, Domains. Add the apex and www. Wait until both say valid and the certificate is issued.
  8. Set the apex as primary. Keep vercel.app as a redirect.
  9. Change the privacy contact from privacy@pow3folio.vercel.app to an address on the new domain.
  10. Do not switch nameservers unless you want Vercel to own every DNS record. A and CNAME are enough.

Security before strangers arrive.

  1. RLS on profiles, trades, writings, community, airdrops, credentials and storage. A logged-out user must not update another row.
  2. Service role key stays on the server. Search the client bundle before launch.
  3. Auth redirects only allow the live domain.
  4. Rate-limit autofill, OTP, wallet challenge and reports.
  5. Ops MFA on every admin account. The screen exists. Confirm it is required.
  6. Wallet login must reject a reused nonce.
  7. Public storage only for images meant to be public. Documents linked from the CV should be unguessable.
  8. npm audit and a dependency pass before the launch week.

Legal, Nigeria first.

  1. Search Powfolio on the trademark portal and the web before paying for a mark.
  2. If money comes in, register a CAC business name. A limited company can wait.
  3. Privacy and terms must name the live domain, the contact, and Supabase, Vercel and Google.
  4. NDPR: why email, wallet and location are collected. Location stays optional. Deletion already exists.
  5. Cookie banner must block non-essential tags until accepted.
  6. Scores are profile and builder scores, not verified income.

Growth after the link is stable.

  1. Your own public profile is the sample. It has to survive a cold visit.
  2. One X thread from @cryptoadvancers after the domain resolves. No paid promo first.
  3. Twenty real profiles from Cryptoadvancers before a directory. An empty directory looks broken.
  4. Weekly: one profile note, one product fix, one community prompt.
  5. Directory after those profiles. Employer shortlist after the directory.
